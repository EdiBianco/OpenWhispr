Termux and terminal apps

Dictate into Termux without leaving the terminal.

Termux's main terminal area is not a standard Android text field, so swipe the extra keys row left or right to switch to its native text input box, then dictate there. OpenWispr transcribes your speech and inserts the text as you spoke it — including shell flags, paths, and punctuation.

How it works

  1. 1
    Tap the overlay button

    A small floating button lives on top of your apps. Tap it once to start recording.

  2. 2
    Speak

    Dictate naturally. The button pulses red while it's listening.

  3. 3
    Tap again to stop

    The button turns gray while the transcription runs.

  4. 4
    Audio is transcribed

    On-device using local models, or sent to Groq Whisper with your own API key.

  5. 5
    Text is inserted

    The transcribed text goes into the currently focused field when the app exposes a standard Android input field. If insertion fails, it falls back to the clipboard.

Voice commands

Say “Whisper Command” with one of five actions, and OpenWispr applies it to whatever is already in the focused field — or to text you dictate right after the command.

You can also dictate first and command last: speak your text, then say the trigger phrase and the action. The text before the trigger is what the command works on.

  • Summarize — “Whisper Command, summarize this in two sentences”
  • Improve the flow — rewrite for smoother, more natural flow without changing meaning
  • Translate — “Whisper Command, translate to Italian”
  • Change the tone — formal, casual, professional, friendly
  • Reformat — “Whisper Command, turn this into a list”

Chain them in one breath, and they apply in order: “Whisper Command, translate to Italian and turn it into a list” translates first, then lists the result. Anything outside these five is refused rather than guessed at. Off by default — enable it, and change the trigger phrase, under Voice Commands in the app.

Local or cloud — your choice

No backend is involved. Local mode uses your own hardware; cloud mode goes straight from your phone to the service you choose, with your own API key.

Local mode

  • On-device transcription
  • Audio never leaves your phone
  • No API key required
  • Download a model once, use it offline

Cloud mode

  • Uses Groq Whisper API
  • Your own API key, stored on-device
  • No backend run by me
  • Optional: send transcript to Groq for cleanup
Requests go straight from your phone to Groq. No relay server is involved.

Why Accessibility permission is needed

OpenWispr uses Android Accessibility Service for one narrow reason: inserting dictated text into the currently focused text field across apps.

It does not replace your keyboard. It does not run background automation. It only acts after you explicitly tap the overlay button.

The app is open source. You can read exactly what it does before granting the permission.

FAQ

Why not just make it a keyboard?

A custom keyboard means replacing your existing keyboard entirely. That's a lot of friction. OpenWispr leaves your keyboard alone and works on top of any app, any keyboard.

Why does it need Accessibility permission?

Android doesn't have a standard API for inserting text into another app's focused field. The Accessibility Service is the sanctioned way to do that cross-app. OpenWispr uses it for exactly one thing: inserting the transcribed text.

Does audio stay on-device?

In local mode, yes. In cloud mode, audio is sent directly to Groq's API from your device using your own API key. I don't have a backend and never see your audio.

Does it work in every app?

It works in most apps with standard text fields. Some apps restrict text injection for security reasons, and others use custom text surfaces instead of normal input fields. In those cases, the transcribed text is copied to your clipboard as a fallback.

How does it work in Termux?

Termux's main terminal area is not a standard Android text field, so direct insertion may not work there. Swipe the extra keys row left or right to switch to Termux's native text input box, then dictate there.

Is it on the Play Store?

No. OpenWispr ships as a signed APK from GitHub Releases, and the app updates itself in place from there. Play Store distribution may come later.

Is this finished?

It is a working daily-driver: on-device or cloud transcription, optional cleanup, voice commands, a custom dictionary, backup and restore, and in-app updates. It is still improved in public, and issues are welcome.
